# M2 实验开发日志（pstree - 进程树打印）

## 项目概述
M2实验要求实现一个类似于`pstree`命令行工具的功能，用于打印当前进程及其父进程下的所有子进程，形成一个进程树结构。

### 阶段2：代码框架设计 (2026-08-07 15:15)

**设计决策**：

1. **命令行解析**
   - 使用POSIX标准的`getopt_long()`函数处理长选项
   - 支持短选项（-p, -n, -V, -h）和长选项（--show-pids, --numeric-sort, --version, --help）

2. **进程信息结构**
   ```c
   typedef struct {
       pid_t pid;              // 进程ID
       pid_t ppid;             // 父进程ID
       char comm[256];         // 进程名称
   } ProcessInfo;
   ```

3. **递归打印树结构**
   - 使用递归方法`print_tree()`打印进程树
   - 使用树形符号（├──、└──、│）显示层级关系
   - 缩进参数用于标记树的深度

4. **排序方式**
   - 默认按进程名称字母排序
   - `-n`选项时按PID数值排序
   - 使用`qsort()`进行排序

### 阶段3：核心功能实现 (2026-08-07 15:30)

**实现的主要函数**：

#### 1. 进程信息读取函数

**`read_comm()`** - 从/proc/{pid}/comm读取进程名称
```
目的：获取进程的可读名称
实现：
- 构造/proc/{pid}/comm文件路径
- 打开并读取文件内容
- 移除末尾的换行符
- 返回成功/失败状态
```

**`get_ppid_from_stat()`** - 从/proc/{pid}/stat获取父进程ID
```
目的：解析进程的父进程ID
实现：
- 构造/proc/{pid}/stat文件路径
- 读取一行内容
- 使用sscanf()解析格式：pid (comm) state ppid ...
- 返回解析出的ppid
```

#### 2. 排序比较函数

**`cmp_pid()`** - 按PID排序的比较函数
```
用途：qsort()回调函数，按PID进行数值排序
```

**`cmp_name()`** - 按名称排序的比较函数
```
用途：qsort()回调函数，按进程名称进行字典序排序
```

#### 3. 树结构打印函数

**`print_tree()`** - 递归打印进程树
```
参数：
- processes：进程信息数组
- count：进程总数
- parent_pid：当前打印的父进程ID
- current_pid：当前进程ID（用于标记"<== me"）
- indent：缩进字符串
- is_last：标记是否为最后一个子进程
- show_pids：是否显示PID
- numeric_sort：是否按PID排序

算法：
1. 从processes数组中找出ppid=parent_pid的所有子进程
2. 根据选项对子进程排序
3. 递归打印每个子进程
4. 为下一级调用构造适当的缩进字符串
```

#### 4. 主函数`main()`

```
流程：
1. 定义长选项数组
2. 使用getopt_long()解析命令行参数
3. 处理各个选项标志
4. 获取当前进程(self)和父进程信息(parent)
5. 打开/proc目录
6. 扫描/proc目录下的所有进程
7. 读取每个进程的pid、ppid、comm信息
8. 存储到processes数组
9. 调用print_tree()打印进程树
10. 清理资源
```

## 主要设计决策和技术细节

### 1. 使用/proc文件系统
**原因**：
- Linux标准做法
- 便携性强
- 实时获取进程信息
- 无需特殊权限

**关键文件**：
- `/proc/{pid}/comm` - 进程名称（简短版本）
- `/proc/{pid}/stat` - 进程统计信息（包含ppid）

### 2. 递归打印树结构
**优点**：
- 代码简洁清晰
- 自然表达树形结构
- 易于处理任意深度

**缺点**：
- 可能导致栈溢出（对于很深的进程树）
- 本实验中问题不大

### 3. 使用qsort()进行排序
**选择理由**：
- 标准库函数，性能好
- 灵活的比较函数
- 支持多种排序方式

### 4. 树形符号的选择
```
├── 表示中间的分支
└── 表示最后的分支
│   表示竖线连接
```
这个选择提高了输出的可读性。

## 遇到的问题和解决方案

### 问题1：进程树的完整性
**问题描述**：初期代码只打印直接的子进程，无法递归显示孙进程及更深层的进程。

**解决方案**：
- 改进print_tree()函数为递归版本
- 正确处理缩进字符串
- 递归调用自身处理每个子进程的子树

### 问题2：缓冲区溢出风险
**问题描述**：固定大小的path和line数组可能不足。

**解决方案**：
- 对char comm[256]使用strncpy()确保不越界
- 在路径构造中使用snprintf()
- 明确指定缓冲区大小

### 问题3：排序稳定性
**问题描述**：需要支持不同的排序方式（按名称或按PID）。

**解决方案**：
- 实现两个比较函数：cmp_pid()和cmp_name()
- 根据numeric_sort标志选择使用哪个比较函数

### 问题4：进程ID标记的准确性
**问题描述**：需要准确标记当前进程（"<== me"）。

**解决方案**：
- 在main()中获取当前进程的PID
- 递归传递current_pid参数
- 在打印时与每个进程的PID比较

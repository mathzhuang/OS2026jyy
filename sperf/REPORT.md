## 实验原理

### 系统调用的概念

系统调用（System Call）是应用程序向操作系统内核请求服务的接口。每次调用系统调用都会从用户态切换到内核态，执行相应的操作，然后返回用户态。

**系统调用的性能特征**：
- **调用次数**：程序进行了多少次系统调用
- **执行时间**：每次系统调用耗费的时间
- **等待时间**：系统调用在等待I/O时的时间

### strace工具

strace是Linux系统调用跟踪工具，它能够：
- 截获程序执行的所有系统调用
- 显示调用的参数和返回值
- 记录每次调用的执行时间

**strace输出格式**（-e trace=all）：
```
syscall_name(arg1, arg2, ...) = return_value <execution_time>
例如：
read(3, "\x7fELF\x02\x01\x01", 832) = 832 <0.000012>
write(1, "hello\n", 6)              = 6 <0.000008>
```

### sperf的设计原理

sperf作为strace输出的分析工具，通过：
1. **解析**：将文本行转换为结构化数据
2. **统计**：聚合相同系统调用的信息
3. **分析**：计算各项统计指标
4. **展示**：按不同维度排序和输出

### 2. 核心数据结构

**单个系统调用的统计信息**：
```c
typedef struct {
    char name[64];      // 系统调用名称
    long count;         // 调用次数
    double time;        // 总执行时间(微秒)
    double max_time;    // 最大执行时间
    double min_time;    // 最小执行时间
} syscall_stat;
```

**全局统计集合**：
```c
typedef struct {
    syscall_stat stats[MAX_SYSCALLS];  // 最多1024个不同的系统调用
    int count;                          // 实际的系统调用种类数
    double total_time;                  // 所有系统调用的总时间
    long total_calls;                   // 所有系统调用的总次数
} syscall_stats;
```

### 3. 主要算法

#### 3.1 strace行解析算法

```
输入：strace格式的一行文本
输出：系统调用名称和执行时间（或失败）

步骤：
1. 移除行首尾空白
2. 检查是否为空行或注释
3. 查找第一个'('，之前为系统调用名称
4. 验证名称合法性（只含字母、数字、下划线）
5. 查找'<'和'>'，提取时间字符串
6. 使用strtod()将时间字符串转换为double
7. 转换单位：秒 → 微秒（乘以1,000,000）
8. 返回成功
```

**时间复杂度**：O(n)，n为行的长度  
**空间复杂度**：O(1)

#### 3.2 统计更新算法

```
输入：系统调用名称和执行时间
输出：更新的统计数据

步骤：
1. 在统计数组中查找该系统调用（线性查找）
2. 如果找到：
   a. count++
   b. time += 新的执行时间
   c. max_time = max(max_time, 新时间)
   d. min_time = min(min_time, 新时间)
3. 如果未找到且数组未满：
   a. 创建新条目
   b. 初始化为第一次调用的信息
4. 更新全局统计（total_time, total_calls）
```

**时间复杂度**：O(m)，m为不同系统调用数量  
**优化**：可使用哈希表将其优化为O(1)

#### 3.3 排序算法

使用标准qsort()进行排序，支持三种方式：

- **按调用次数**（默认）：降序排列
  ```c
  cmp_count: if (count_b != count_a) return count_b - count_a
  ```

- **按执行时间**：降序排列
  ```c
  cmp_time: if (time_b != time_a) return (time_b > time_a) ? 1 : -1
  ```

- **按名称**：升序排列
  ```c
  cmp_name: return strcmp(name_a, name_b)
  ```

**时间复杂度**：O(n log n)，n为系统调用种类数

## 代码示例

### 关键实现片段

**strace行解析**：
```c
int parse_strace_line(char *line, char *syscall_name, double *time) {
    // 1. 清理字符串
    char *trimmed = trim_whitespace(line);
    
    // 2. 提取系统调用名称
    char *paren = strchr(trimmed, '(');
    int name_len = paren - trimmed;
    strncpy(syscall_name, trimmed, name_len);
    
    // 3. 提取执行时间
    char *time_start = strchr(paren, '<');
    char *time_end = strchr(time_start, '>');
    
    // 4. 转换时间值
    char time_str[64];
    strncpy(time_str, time_start+1, time_end-time_start-1);
    double time_seconds = strtod(time_str, NULL);
    *time = time_seconds * 1000000.0;
    
    return 1;
}
```

**统计更新**：
```c
void add_syscall(syscall_stats *stats, const char *name, double time) {
    int idx = find_syscall(stats, name);
    
    if (idx >= 0) {
        // 更新现有条目
        stats->stats[idx].count++;
        stats->stats[idx].time += time;
        stats->stats[idx].max_time = MAX(stats->stats[idx].max_time, time);
        stats->stats[idx].min_time = MIN(stats->stats[idx].min_time, time);
    } else {
        // 创建新条目
        idx = stats->count++;
        strcpy(stats->stats[idx].name, name);
        stats->stats[idx].count = 1;
        stats->stats[idx].time = time;
        stats->stats[idx].max_time = time;
        stats->stats[idx].min_time = time;
    }
    
    stats->total_time += time;
    stats->total_calls++;
}
```
